# Pharmacy-Management-System

The Pharmacy Management System demonstrates user registration and authentication, role-based access, medicine inventory management, bill generation, automatic stock updates, and customer billing-history retrieval using Python and SQLite.
The Pharmacy Management System is a simple command-line application developed using Python and SQL to manage pharmacy information. The system allows authorized users to log in using a username and password. After login, users can add, view, update, search, and delete medicine records. The database consists of four main tables: Users,Pharmacist ,Medicines and Bills. 
The USERS table stores the login details of users and pharmacists. The BILLS table stores the details of each transaction.It records the pharmacist who generated the bill, the number of items, total amount, and date of the transaction.The system uses CRUD operations to manage the medicine records.
This project demonstrates the use of Python programming, SQL database management, user authentication,CRUD operations, and a simple command-line interface for developing a basic pharmacy management system.
